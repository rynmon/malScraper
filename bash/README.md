# ⚠️ DEPRECATED: Bash Version

**This Bash version of malScraper has been deprecated as of v1.5.0.**

## Migration

Please use the **Rust version** instead, which provides:
- Cross-platform compatibility (Windows, macOS, Linux)
- Better performance
- Single binary distribution
- Continued active development

### Download

Get pre-built binaries from the [main repository releases](https://github.com/rynmon/malScraper/releases).

### Why Deprecated?

The Rust version offers significant advantages:
- **Cross-platform**: Works on Windows without WSL
- **Performance**: Much faster than shell scripts
- **Distribution**: Single executable
- **Maintenance**: Easier to maintain

---

**Please migrate to the Rust version for continued support.**
